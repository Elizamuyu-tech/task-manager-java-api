# 📋 Task Manager API - Backend em Java & PostgreSQL

API RESTful completa para gerenciamento de tarefas e usuários, desenvolvida com **Java 17** e **Spring Boot**, aplicando autenticação via **JWT (JSON Web Token)** e persistência em banco relacional **PostgreSQL**.

---

### 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java 17
- **Framework:** Spring Boot 3 (Spring Web, Spring Security, Spring Data JPA)
- **Banco de Dados:** PostgreSQL
- **Autenticação:** JWT (JSON Web Token)
- **Documentação:** Swagger / OpenAPI
- **DevOps:** Docker & Docker Compose

---

### 📌 Principais Funcionalidades

- 🔐 **Autenticação & Autorização:** Cadastro de usuários e login com geração de token JWT.
- 📝 **CRUD de Tarefas:** Criação, listagem, atualização e exclusão de tarefas vinculadas ao usuário autenticado.
- 🎯 **Filtros e Status:** Controle de prioridades e status das tarefas (Pendente, Em Andamento, Concluída).
- 📖 **Documentação Interativa:** Interface Swagger UI para teste dos endpoints.
